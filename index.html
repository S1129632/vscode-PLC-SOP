Six Rockwell PDF references and the NIST SP 800-82r3 OT security guide were supplied for this prototype, but this browser app does not load or compare their contents at runtime. Review the findings and source documents below; verify technical details against the approved documents before use.

Source-based findings

Reference document review

Reviewed manually
  • 1756-UM001Q-EN-P, ControlLogix 5570 and 5560 Controllers User Manual (December 2024): Chapter 3, pages 58–62, covers setting the communication path, going online, and uploading from the controller. Page 62 directs the engineer to verify the project in the Connected to Upload dialog box before selecting Upload. The manual's stated controller scope is 5570/5560; it does not validate a procedure for all Ethernet-connected PLC families.
  • 1756-RM014D-EN-P, Logix 5000 Controllers Import/Export Reference Manual (September 2025): this is the supplied Import/Export manual, not the Design Considerations manual.
  • 1756-RM094-EN-P, Logix 5000 Controllers Design Considerations Reference Manual: supplied and applicable to Logix 5000 design considerations.
  • 1756-PM001, Logix 5000 Controllers Common Procedures Programming Manual: the supplied PDF is a one-page manual list. It identifies Import/Export as publication 1756-PM019; it is not the Import/Export manual itself.
  • ENET-UM001, EtherNet/IP Network Configuration: the supplied cover states this manual has been replaced by ENET-UM006.
  • ENET-UM006C-EN-P, EtherNet/IP Network Devices User Manual (September 2025): supplied as the replacement for ENET-UM001 and covers EtherNet/IP network devices, workstation configuration, IP addressing, and device configuration.
  • NIST SP 800-82 Revision 3, Guide to Operational Technology (OT) Security: supplied for OT cyber-security guidance. It supports security principles and safeguards, but is not a Rockwell controller operation manual and does not replace model-specific procedures.
  • Studio 5000 Logix Designer Online Help: a web-based Rockwell resource, not a downloadable document placed in this workspace. It can supplement the PDF sources, but it must be checked against the relevant software version.

Coverage conclusion: 1756-RM094 covers Logix 5000 design considerations across the applicable ControlLogix and CompactLogix families, while 1756-UM001 provides the controller-specific procedure for ControlLogix 5570/5560 going online and uploading. ENET-UM006 covers EtherNet/IP network devices and addressing. NIST SP 800-82r3 provides OT cyber-security guidance. The supplied Studio 5000 Online Help website is retained as a version-specific software reference. No additional PDF source is currently identified as missing. No automatic comparison or technical approval is performed by this app.
